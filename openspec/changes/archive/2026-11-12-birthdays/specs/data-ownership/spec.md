# Spec Delta

## MODIFIED Requirements

### Requirement: Только свои контакты в списке и поиске

Общий список, поиск, счётчик контактов, блоки «Пора связаться» и «Скоро день рождения» SHALL показывать только контакты вошедшего пользователя. В «Найдено N из M» M MUST быть числом его контактов.

#### Scenario: Чужой контакт не в списке
- **WHEN** A добавил контакт «Анна Соколова», а B открывает главную
- **THEN** в списке B нет «Анна Соколова»

#### Scenario: Чужой контакт не находится поиском
- **WHEN** B ищет «Соколова», а такой контакт есть только у A
- **THEN** у B «Никого не нашлось по запросу «Соколова»»

#### Scenario: Счётчик
- **WHEN** у A 3 контакта, у B 2, и B ищет по имени
- **THEN** у B под заголовком «Найдено N из 2»

#### Scenario: Пора связаться
- **WHEN** у A есть контакт, с которым пора связаться
- **THEN** в блоке «Пора связаться» у B его нет

#### Scenario: Скоро день рождения
- **WHEN** у A есть контакт, у которого завтра день рождения
- **THEN** у B блока «Скоро день рождения» с этим контактом нет
