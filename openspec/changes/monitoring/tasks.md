Код приложения не меняется. По CLAUDE.md сервер, скрипты выкатки и CI проверяются настоящей выкаткой, без автотестов. Поэтому «тест» здесь - проверка руками, записанная в задаче. Порядок тот же, что в TDD: сначала проверка и убедиться, что сейчас она не проходит, потом правка, потом проверка проходит. Шаги, которые делает пользователь (ключи, `.env`, sudo, Deploy prod, UptimeRobot), помечены «Пользователь». Остановка чего-либо на сервере для проверки - только после его «да».
